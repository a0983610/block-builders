# 積木小人 · 世界地標工地　`v1.185.0`

一進來就有一座蓋好的世界地標。你把它砸爛，小人們才會從滿地的碎料裡
一塊一塊搬出來，慢慢蓋出下一座。被打到的地方才會壞，沒波及的地方原封不動。

three.js ＋ 原生 JavaScript，沒有建置步驟、沒有套件相依、不連網路。

## 怎麼開

**雙擊 `index.html` 就能玩**，不用開 server。
要做自訂藍圖的話開 **`藍圖預覽.html`**：拿 prompt、看藍圖蓋起來的樣子、跑體檢、複製報告給 AI。

## 要傳給別人玩

**雙擊 `tools/export-game.bat`**（或 `python tools/export-game.py`）。
它把跑得起來的那幾支挑出來放進 `dist/積木小人-v版號/`，整個資料夾丟出去就能玩：

| | 內容 | |
|---|---|---|
| 預設 | `index.html` ＋ `lib/` ＋ `src/` ＋ `blueprints/`（28 座）＋ `藍圖預覽.html` | 40 支、2.3 MB |
| `--min` | 只有遊戲本體（`index.html` ＋ `lib/` ＋ `src/`） | 10 支、2.1 MB |

還有 `--zip`（順便壓一包）、`--list`（只印會匯出哪些檔）、`--clean`、`--out 路徑`。
**要匯出哪些檔是從 `index.html` 讀出來的**，不是寫死的清單——之後多一支 `.js`、
多一座藍圖，這支腳本不用跟著改。

**收到的人要先解壓縮出來**再開裡面的 `index.html`——直接在壓縮檔裡按兩下的話
Windows 只會解出那一支檔，旁邊的 `lib/`、`src/` 都不在。真的漏了也不會只剩一片空白：
開場會先確認八支相依檔都載到了，沒到就蓋一層說明講缺哪幾支、要怎麼做。

## 遊玩循環

```
開場：一座蓋好的建築（完工）
  ↓ 你動手砸
拆除中：小人照樣過自己的生活（不會偷偷幫你修）
  ↓ 拆到只剩 25% 以下
剩下的自己垮掉 → 隨機開下一座地標
  ↓ 推土機進場
整地中：一排推土機並排掃過整個工地，把碎料推出範圍，掃完小人才開工
  ↓ 小人搬運施工
完工 → 繞圈慶祝 → 回到開頭
```

還沒蓋完就被砸的話，小人**會**把洞補回去——那是修補，跟拆除是兩回事。

不想等小人搬完，左下面板有 **⚡ 立刻建成**：整座直接長出來，phase 跳到完工。
它不累積人力費，所以按不出「百萬工程」那種花錢成就，施工計時也歸零（順帶擋掉比速度的
「奇蹟工程」）；蓋過哪些地標、幾塊的大工程照記。

## 操作

| 動作 | 效果 |
|---|---|
| 點建築 | 用目前的道具攻擊。散開的方向跟你從哪個角度點有關 |
| 點空地 | 大槌＝地震；**點兩下**的有保齡球（出手點 → 方向）、龍捲風、大劍、王之財寶、箭雨、投石機；炸彈、隕石、核彈、魔法、幽浮本來就是「選一個地點」。小槌點空地只是敲地板，建築不受影響 |
| 點小人 | **拿👆手指才戳得倒**（他會仰躺在地上，手上的積木掉下來）。拿🔥放火是點燃他。其餘破壞道具不理小人，射線直接穿過去打他背後的東西 |
| 拖曳 | 轉視角 |
| WASD | 平移鏡頭（桌機。方向以畫面為準，不是世界軸） |
| Q／E | 左右轉視角（桌機。跟拖曳同一套，E 對應往右拖） |
| Z／X | 視線降低／升高（桌機。像搭電梯，上下界跟著這一座建築走） |
| C | 回到開場的鏡頭（距離、視線高、中心、角度都回去） |
| 滾輪 / 雙指 | 縮放 |
| 工具小窗 | 顯示現在拿的是哪一把；滑鼠指上去（觸控是點一下）展開選單切換 |
| 左下面板 | 選建築、建材數（1800／3000／9000，預設 3000）、小人數（20／40／60，兩人以上會有一個當工程師）、時間倍率（0.5×／1×／4×）、換一座來蓋、⚡ 立刻建成 |
| 右上 | 現在時間、本座施工計時、累計破壞損失、成就 |

## 場上有什麼

### 建築

48 座（地標 36、動物 4、交通工具 4、特殊 4）各是一個吃尺度參數 `s` 的 voxel 產生器，
積木數不寫死：`fitScale()` 拿實際格數掃 `s`，找最接近目標的那個尺寸。
另外還有 `blueprints/` 底下的自訂藍圖（見下一節），會排在選單最前面加 ★。

積木只看「連不連得到地面」決定會不會垮：打穿牆腳，上面整片靠左右兩側撐住是常態，
撐不住的那一塊會自己掉下來，連鎖垮塌就是這樣來的。

### 破壞道具

19 把。**免解鎖的是 👆手指、🪣水桶、🔨槌子**，其餘每累計擊飛 2000 塊解鎖一把
（🔨大槌 → 🎳保齡球 → 🪨投石機 → 🌪龍捲風 → 🎆煙火 → 🔥放火 → 💣定時炸彈 →
☄隕石 → ☢核彈 → 💥爆裂魔法 → ⚡打雷 → ⚫天降鐵球 → 🗡王之財寶 → ⚔大劍 →
🛸幽浮 → 🏹箭雨）。

每一把的用法寫在道具選單的說明裡（來源是 `game-tools.js` 的 `TOOLS`，畫面上那份選單
就是照它生出來的），怎麼實作的、當初為什麼那樣調，在 `開發筆記.md` 的〈破壞道具〉。

### 小人

搬料、蓋、修補、逃命、慶祝，還有各自的日常：**工程師**（兩人以上就有一個）在旁邊指揮、
**魔法師**（5 號）站在料堆旁隔空把碎料拋到定位、**肌肉小人**（每十人一個）撿起來就地掄過去，
閒著會**聊天、絆倒、跳舞、打架**，頭上冒**表情圖示**。沒事幹的時候一定會發生一件**閒晃事件**——蓋自己的小房子、種樹。
施工中也有人**偷懶**，跑去過閒晃模式的生活。

小人會被破壞道具波及：戳倒、震倒、炸飛（還會被點著）、被龍捲風捲上天、被保齡球撞飛。
倒地的趴一下自己爬起來，燒完拍拍灰站起來。

### 動物、天災與吉祥物

- **閒逛的動物**：乳牛、公牛、綿羊、公羊、梅花鹿、雄鹿、豬、山豬八款，場上 5～8 隻，
  一款一個腳程，在整片碎料場裡到處走（不穿地標與小房子）。
- **天災**：🐒黑獼猴放火、🐵白猴子丟香蕉炸彈、🐉飛龍噴火、🦅獅鷲降落噴火。
  飛龍與獅鷲都會地面行走、著火、倒地。
- **吉祥物**：跟天災同一批動物，但是站你這邊的；偶爾動手砸的是村子那邊。
  剛好抽到同一種天災就會就地翻臉。

天災與吉祥物在測試裡預設關掉（它們會隨機干擾別的量測）。

### 水與火

🪣水桶倒出來的水是**一格一格的積木型水**，會流、會積、杯壁破洞就從破口噴出去；
淋到的積木與小人濕 5 秒，點不著。火會往旁邊蔓延，燒到的積木焦黑、鬆脫、掉下來。
建造中失火會有**消防車**開到火場旁邊放水柱。

## 自訂藍圖

`blueprints/` 底下一座建築一支 `.js`，在 `list.js` 加一行就會出現在選單裡。

做法是**設計給 AI 走的**：開 `藍圖預覽.html` → 複製那份 prompt 跟一張參考圖給 AI →
把它吐出來的整段程式貼回預覽頁的貼上框 → 當場看它蓋起來的樣子、按「檢查藍圖」跑體檢 →
不滿意就把報告複製給 AI 叫它改。定案了另存成 `.js` 放進 `blueprints/`。

格式說明在 `blueprints/藍圖製作說明.md`（那份也是 prompt 的本體，
改完要跑 `node tools/build-bpdoc.cjs` 重新包成 `src/bpdoc.js`）。
`blueprints/範例-小教堂.js` 是照著改就能做自己的十四個部件範例。

遊戲裡也有一顆 **📥 匯入建築**，可以直接吃 `.js` 或貼上的程式，不必放進資料夾。

## 成就與紀錄

十九個成就分四組（蓋、拆、小人、錢），每組都有「入門」跟「下一階」兩個門檻。
兩筆錢：**人力金額**（每個小人每秒 $3，只在施工中累積）、**破壞損失**（每塊掉下來的積木 $85）。

紀錄與面板設定自動存在瀏覽器的 localStorage。成就面板上有 `⬇ 匯出存檔`／`⬆ 匯入存檔`
可以搬到別台電腦（匯入是直接覆蓋，不合併）。

## 開發

### 版本號

版本號寫在 `src/game.js` 最上面的 `VERSION`，畫面右下角會顯示。**一律三段** `x.y.z`。

**每次 commit 都要動版本號**：一般改動 `patch +1`，功能性改動 `minor +1`（patch 歸零）。
改完**三個地方要一致**，e2e 有兩條守著：

| 地方 | |
|---|---|
| `src/game.js` 的 `VERSION` | 本尊 |
| `README.md` 第一行 | 這份 |
| `藍圖預覽.html` 的 `VIEWER_VER` | 那一頁不載遊戲層，所以自己留一份 |

### 跑測試

```
node tools/e2e-3d.cjs                       全部跑一輪（完整檔，使用者指定才跑）
node tools/e2e-3d.cjs --tier must           改一行先跑這個：骨架＋核心行為（完整輪的 1/4）
node tools/e2e-3d.cjs --tier commit         commit 前跑這個（完整輪的 1/2，約 4 分鐘）
node tools/e2e-3d.cjs --list                印出每一段的段名／等級／起始行／行數／ok() 行數就結束
node tools/e2e-3d.cjs --until 完工慶祝      開發用：跑到那一段結束就收工
node tools/e2e-3d.cjs --seed 12345          照這個種子重跑＝同一副骰子
node tools/e2e-3d.cjs --json out.json       每一條的結果寫成 JSON（找偶發用）
node tools/e2e-3d.cjs --update-models --until 造型基準    改了造型才用，重產基準檔
node tools/e2e-3d.cjs --update-varying a.json b.json     重產浮動條目清單
node tools/check-bp.cjs --all               48 座藍圖體檢（幾秒鐘）
```

**不想打指令的話雙擊 `tools\run-tests.bat`**：出一份選單（必要檔／commit 檔／完整輪／
跑到某一段／段落一覽／藍圖體檢），選一個數字就開跑，跑完報花了多久。
帶參數也行（`run-tests.bat --tier must`），那時就不出選單。

需要 Playwright 與 chromium；找不到時腳本會印出安裝方式。全部通過 exit 0。
截圖產物在 `tools/.e2e-out/`（已 gitignore）。

測試一定跑真瀏覽器，因為這支程式的坑都在「真實環境與假物件的差異」：
ES module 的 CORS、canvas 是 replaced element、WebGL 的 drawingBuffer 合成後會被清空。
headless chromium 用 SwiftShader 軟體算圖，所以測出來的 fps 沒有參考價值；
效能那段量的是 CPU 端成本（`step` + `draw`），那個跟顯示卡無關。

**什麼時候跑哪一檔、紅了怎麼查、什麼時候不算是程式壞掉**：見 `CLAUDE.md`〈測試與驗收〉。

### 換 three 版本

把原始碼解壓到 `three.js-master/`（此目錄不進 git，576 MB），然後 `node tools/build-three.cjs`。
打包器會比對對外名稱是否與官方 `three.cjs` 完全一致（441 個），少一個就直接失敗。

## 已知限制

- **造型品質不齊**。金字塔、艾菲爾鐵塔、台北 101、天壇、金門大橋、城堡、五重塔這些很好認；
  聖母院、獅身人面像最弱。雪梨歌劇院是刻意的簡化，不是照著蓋的。
- **小尺寸貼不齊**。像台北 101 有八節、吳哥窟有五塔，造型本身就有最少積木數，
  設 400 塊時它們給的是 600～700 塊。預設的 3000 塊那一檔 48 座都在 5% 以內，
  中間的 1500 最差 −11%（吉薩金字塔）。HUD 一律顯示真實塊數。
- **垮塌只看「連不連得到地面」，不算力矩**。往外伸很長的懸臂只要還連著就不會斷，
  真實建築早就折了。支撐關係算 26 鄰居（斜角接觸也算）。
- **施工中挨一發大爆炸會進入「蓋上去→又垮掉」的循環**（實測 60 秒淨進度大約 0）。
  既有行為，還沒處理。
- **積木之間沒有碰撞**。碎塊落地後只做水平分離避免重疊，不會堆疊成山。
- **龍捲風很強**。一發常常能吃掉一整座建築的大半，還可以同時來四道。
  嫌太猛就調 `game-tools.js` 的 `TW_R`／`TW_LIFE`／`TW_MAX`。
- **拆除門檻是寫死的 25%**（`game-save.js` 的 `WRECK_AT`），拆到剩 25% 以下就換下一座，
  但會先原地等 3 秒讓收尾演完。
- **整地不是把地掃乾淨，是把堆起來的推開**，一般大小的工地推得掉八成上下；
  **寬度就是時間**，最寬的那幾座要二十秒以上。
- **煙火在天上的時候，正在燒的積木暫時不冒火苗**（火苗與火星共用同一個粒子池）。
