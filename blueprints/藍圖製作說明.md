# 藍圖製作說明（寫給 AI 看的）

你的任務：**看一張圖片（或一段文字描述），產生一支藍圖 `.js` 檔**，放進這個資料夾，
遊戲下次開啟就會把它加進建築清單，跟內建的 36 座地標一樣可以蓋、可以拆。

做完要交付兩件事，缺一不可：

1. 新檔案 `blueprints/<名字>.js`
2. 在 `blueprints/list.js` 的陣列裡加上那個檔名

> 為什麼要第 2 步：遊戲是用 `file://` 直接開的（不架伺服器），
> 而 `file://` 沒辦法列出資料夾內容——`fetch` 會被 CORS 擋掉。所以檔名得自己列。

---

## 1. 檔案長什麼樣

一支檔案 = 呼叫一次 `customBlueprint({...})`。最小可用的樣子：

```js
customBlueprint({
  name: '我的塔',          // 下拉選單上的名字，不能跟現有的撞號
  pal: ['#c8a06a', '#8a5a3c', '#c0483c'],   // 顏色表，最多 9 個
  layers: [
    // y=0（貼地那一層）
    ['111',
     '111',
     '111'],
    // y=1
    ['1.1',
     '...',
     '1.1'],
    // y=2
    ['222',
     '222',
     '222']
  ]
});
```

**座標系**（很重要，弄反了造型會躺著）：

| 東西 | 意義 |
|---|---|
| `layers` 的索引 | **y，高度**。`layers[0]` 是貼地那一層，往後越來越高 |
| 一層裡字串的索引 | **z，往畫面深處**（第 0 個字串是最靠近鏡頭那一排） |
| 字串裡字元的索引 | **x，往右** |

**字元**：`1`–`9` = `pal` 的第 1–9 個顏色；`.`、空白、`0` = 空的。
其他字元會被當成空白，並在 console 留一行警告（不會讓遊戲壞掉）。

各層的長寬不必完全一致，短的會自動補空白——但**建議自己補齊**，
排整齊的圖你自己也比較好檢查。

---

## 2. 大小要抓多少

**基準模型抓在 200～600 格**（也就是 `layers` 裡實心字元的總數）。

遊戲的「建材數」滑桿是 300–3000 塊，載入時會**自動照 s³ 等比縮放**你的模型去湊那個數字，
所以你不用管滑桿、也不用寫 `lo`／`hi`。太小的模型（<80 格）放大後會變成一格一格的馬賽克，
太大的（>1500 格）縮小時細節會被抽掉。

尺寸上限抓 **48×48×48**；超過就開始吃效能，而且遠看也分不出細節。

---

## 3. 造型規則（照著做，蓋出來才會好看又不會壞）

- **一定要有貼地的那一層**（`layers[0]` 不能整層是空的）。遊戲的垮塌判定是從地面往上做
  連通性搜尋，接不到地面的部分會被當成「懸空部件」。
- **懸空部件是允許的**（風車扇葉、拱門下方的空洞都是），它們不會平白掉下來；
  但要記得它們是靠附近的積木撐著，附近被打掉就會整組掉。
- **牆做成中空的**：外面一圈實心、裡面留空。整塊實心會浪費格數，
  而且縮放後看起來就是一坨方塊。
- **對稱的造型左右要真的對稱**。差一格在遊戲裡看得出來。
- **細長的桿子（旗竿、天線）至少 1 格寬**，縮小時會被抽掉是正常的。
- 顏色**分區塊給**，不要一格一色地做漸層——voxel 的顆粒感就是它的味道。

---

## 4. 怎麼從圖片做出來

1. 先決定**朝向**：把圖片裡的正面對到 `z` 小的那一側（也就是 `layers` 裡排在前面的字串）。
2. 量**三個尺寸**：寬（x）、高（y）、深（z），換算成格數，控制在 200～600 格的總量。
3. **從下往上一層一層畫**。每一層問自己「這個高度切一刀，剖面長什麼樣」。
   - 樓層、屋簷、陽台這種水平特徵，就是某幾層突然變寬。
   - 屋頂就是連續幾層逐步變窄（每層縮 1 格＝45 度斜屋頂）。
   - 圓塔就是每層畫一個圓，圓的半徑照高度變化。
4. **顏色**照圖片抓 3–6 個主色，寫成 `pal`。深色留給陰影面與底座，亮色留給屋頂與招牌。
5. 存檔、把檔名加進 `list.js`。

---

## 5. 交出去之前自己檢查

- [ ] `name` 沒有跟內建的 36 座或其他自訂藍圖撞號
- [ ] `layers[0]` 有貼地的實心格
- [ ] 實心格總數落在 200～600
- [ ] 每一層的字串數一致、每個字串長度一致
- [ ] 只用了 `1`–`9` 與 `.`
- [ ] `pal` 的顏色數 ≥ 你用到的最大數字
- [ ] 檔名已經加進 `blueprints/list.js`

檢查完可以直接開 `index.html`，在左下角的下拉選單裡選你的藍圖看效果；
console（F12）如果有 `[自訂藍圖]` 開頭的警告，代表那一份有問題。

---

## 6. 進階：直接寫產生函式

需要圓、螺旋、隨機細節這種「用字元圖畫不出來」的造型時，可以跳過 `layers`，
直接給 `gen(v, s)`，跟內建那 36 座同一套 API（`v` 的完整方法看 `src/blueprints.js` 最上面）：

```js
customBlueprint({
  name: '我的圓塔',
  pal: ['#cfc7b8', '#8d8f92'],
  lo: 4, hi: 18,              // s 的掃描範圍，遊戲會在這中間找最接近目標塊數的尺寸
  gen(v, s) {
    const r = Math.round(s), h = Math.round(s * 3);
    v.cyl(0, 0, 0, r, h, 0, 2);        // 中空圓柱：牆厚 2
    v.cyl(0, h, 0, r + 1, 1, 1);       // 頂端一圈簷
  }
});
```

常用的方法：`box` `walls` `carve` `cyl` `ellipseRing` `taper` `pyramid` `set` `del`。
座標可以是負的（原點在中心），`y` 一律從 0 起算往上。
