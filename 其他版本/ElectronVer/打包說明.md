# 積木小人桌面版（Electron）打包說明

把網頁版《積木小人 · 世界地標工地》包成 Windows 的**單一 exe**（electron-builder 的 portable）。
遊戲本體在 `src/renderer/`（目前是 v1.283.0），桌面版加的部分在 `src/main/`（主行程）與 `src/preload/`（橋樑）。

## 打包的電腦要有什麼

| 條件 | 說明 |
|---|---|
| **Windows x64** | 產出的是 Windows exe，`打包.cmd` 也是 Windows 批次檔。實測環境：Windows 11 Pro x64。 |
| **Node.js 22.12.0 以上**（含 npm） | Electron 44.3.0 的 `package.json` 寫明 `engines.node >= 22.12.0`。實測 Node 22.13.1／npm 10.9.2。 |
| **網路**（第一次） | 要連得到 npm registry 與 GitHub，見下一節。 |
| **硬碟空間約 1.1 GB** | `node_modules` 449 MB ＋ 下載快取 166 MB ＋ 打包時的中間資料夾 324 MB ＋ exe 140 MB（中間資料夾打包完會被 `打包.cmd` 刪掉）。 |

**不需要**的（都實測過）：

- **系統管理員權限、Windows「開發人員模式」**：一般使用者身分、開發人員模式沒開，照樣打包成功。
- **程式碼簽章憑證**：目前產出的 exe 本來就沒有數位簽章（`Get-AuthenticodeSignature` 為 `NotSigned`）。
- **特定的系統語系／字碼頁**：`打包.cmd` 是純 ASCII，字碼頁 950 與 65001 都驗過。

### 第一次會下載的東西

| 下載什麼 | 從哪裡 | 存到哪裡（之後重用） | 大小 |
|---|---|---|---|
| npm 套件（electron、electron-builder…） | `https://registry.npmjs.org/` | 這個資料夾的 `node_modules\` | 449 MB |
| Electron 本體 | `https://github.com/electron/electron/releases/download/` | `%LOCALAPPDATA%\electron\Cache` | 151 MB |
| 打包工具（NSIS、7-Zip） | `https://github.com/electron-userland/electron-builder-binaries/releases/download/` | `%LOCALAPPDATA%\electron-builder\Cache` | 15 MB |

公司網路連不到 GitHub 時，可以用環境變數改走鏡像站：
`ELECTRON_MIRROR`（Electron 本體，見 `node_modules\@electron\get\dist\artifact-utils.js` 的 `mirrorVar`）、
`ELECTRON_BUILDER_BINARIES_MIRROR`（打包工具，見 `node_modules\app-builder-lib\out\util\electronGet.js` 的 `getBinariesMirrorUrl`）。

## 第一次打包

1. 裝好 Node.js（22.12.0 以上）。
2. 把這個資料夾**複製到 git repo 外面**（理由見〈注意〉第 1 點）。
3. 在資料夾裡開命令列，執行 `npm ci`（照 `package-lock.json` 裝完全一樣的版本）。
4. 雙擊 `打包.cmd`。

## 之後每次打包

雙擊 `打包.cmd`，完成後在 `dist\` 拿到 `BlockBuilders-<版本>-portable.exe`。

- 版本號取自 `package.json` 的 `version`；版本沒改的話會**覆蓋** `dist\` 裡同名的 exe。
- 遊戲開著的時候 exe 被鎖住，打包會失敗，先把遊戲關掉。
- `打包.cmd` 會刪掉打包的中間產物（`dist\win-unpacked\`、`dist\builder-debug.yml`），只留 exe。

## 打包設定（`electron-builder.yml`）

- `win.target: portable`：單一 exe。每次啟動會把整個程式解壓到 `%TEMP%\<隨機名稱>` 再執行，正常關閉後自動刪掉。
- `portable.useZip: true`：直接解壓到執行的位置，不經過中間資料夾。實測執行中的暫存從約 840 MB 降到約 324 MB，代價是 exe 從 96 MB 變 140 MB。
- `electronLanguages: [zh-TW, en-US]`：Chromium 介面語系只留兩種（全部 55 種 48 MB → 1.1 MB）。
- `files`：只打包 `package.json` 與 `src/main`、`src/preload`、`src/renderer`。這份說明與 `打包.cmd` 不會進 exe。

## 玩家電腦上會留下什麼

- **存檔資料夾 `%APPDATA%\block-builders`**（成就頁也會顯示這個路徑）。存檔本體在裡面的 `Local Storage\`，其餘是 Chromium 的快取與固定結構，整個刪掉就乾淨。
- **執行中的暫存 `%TEMP%\<隨機名稱>`**：正常關閉會自動刪；被強制結束（工作管理員、當機、直接關機）的話會留下來。

## 注意

1. 這個資料夾放在 `block-builders` 的 git repo 裡（`其他版本/ElectronVer`）。repo 的 `.gitignore` 會忽略 `dist/`，但**不會忽略 `node_modules/`**——直接在這裡 `npm ci` 的話，449 MB 的套件會全部變成未追蹤檔案。
2. `src/renderer/` 是 v1.283.0 的遊戲加上桌面模式的修改，主 repo 的遊戲更新後不會自動跟上。
3. `打包.cmd` 只能寫 ASCII：cmd.exe 讀 `.bat`／`.cmd` 裡的中文會解析錯（同 repo 根目錄 `CLAUDE.md`〈語言〉那條）。
